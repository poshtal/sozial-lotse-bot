# SozialLotse

**Русский** | [English](README.en.md) | [Deutsch](README.de.md)

Telegram-бот на русском языке для людей, которые потеряли работу в Германии
или могут её потерять. Он сам задаёт вопросы, по закону считает право на
Arbeitslosengeld и его срок, показывает, что ещё человеку может быть доступно,
и отвечает на вопросы по тексту SGB III со ссылкой на параграф.

Выпускной проект курса AI Engineer. Как устроен проект и почему так, написано
в [docs/project.md](docs/project.md).

> Это информация, а не юридическая консультация. Окончательное решение всегда
> принимает ведомство.

## Что умеет

- **Анкета.** Положение кнопками, даты свободным текстом («7 ноября»,
  «с 1 июля 24 по сейчас»), опечатку в одну букву исправляет сам. Для тех,
  кому увольнение уже вручили, а работа ещё идёт, есть своя кнопка: бот
  принимает дату в будущем и сразу напоминает, что встать на учёт нужно в
  течение 3 дней (§ 38).
- **Право на пособие.** 12 месяцев работы за последние 30 (§ 142, 143 SGB III).
  Считает код, а не модель.
- **Срок пособия.** От 6 до 24 месяцев по стажу за 5 лет и возрасту (§ 147).
  Возраст спрашивается диапазонами, точное число не нужно.
- **«Что тебе может быть доступно».** До 9 подсказок из каталога, отобранных
  по положению человека: деньги на поиск работы, коучинг, курсы,
  Gründungszuschuss, подработка, Insolvenzgeld и другое.
- **Вопросы по закону (RAG).** Ответ по тексту SGB III со ссылкой на параграф,
  после него 2–3 кнопки «ещё спрашивают».
- **Честные отказы.** Вопрос не по теме, трудовое право и вопрос без ответа в
  законе получают разные ответы. Бот не выдумывает.
- **Ничего не хранит.** Память на час, кнопка «Забудь всё» стирает и память,
  и переписку на экране.

## Запуск с нуля

Нужны Docker Desktop, аккаунт Telegram и бесплатный ключ Gemini API.

1. **Бот в Telegram.** Напиши [@BotFather](https://t.me/BotFather) команду
   `/newbot` и сохрани токен.
2. **Ключ Gemini.** Создай на [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
3. **Настройки.** Скопируй `.env.example` в `.env` и впиши `TELEGRAM_BOT_TOKEN`,
   `GEMINI_API_KEY` и `GEMINI_EMBEDDING_MODEL` (идентификатор модели эмбеддингов
   из AI Studio). Остальное уже заполнено.
4. **Сборка:**
   ```bash
   docker compose build bot
   ```
5. **Загрузка закона в базу знаний.** Один раз, несколько минут:
   ```bash
   docker compose run --rm bot node dist/ingest.js
   ```
   В конце: «Готово: источник sgb-3, версия 1, кусков 385».
6. **Запуск:**
   ```bash
   docker compose up -d bot
   docker compose logs --tail 5 bot
   ```
   В логе: «Бот @имя запущен».

**Проверка.** Напиши боту `/start`, нажми «Окей» и «Недавно уволили, ничего
не получаю», потом задай вопрос «дадут ли денег, если сам ушёл?».

Ожидаемый ответ: при уходе по своему желанию без уважительной причины
наступает Sperrzeit, обычно 12 недель, в некоторых случаях 3 или 6; источник
§ 159 SGB III. Под ответом кнопки «ещё спрашивают».

Telegram разрешает одну копию бота на токен. Если в логе «Этот бот уже
запущен в другом месте», останови вторую копию (например, `npm run start` в
другом окне).

## Настройки `.env`

| Переменная | Что значит | По умолчанию |
| --- | --- | --- |

| `INTERFACE` | `console` включает консоль, даже если токен задан | — |
| `SESSION_TTL_MINUTES` | через сколько минут тишины бот забывает разговор | 60 |
| `GEMINI_API_KEY` | ключ Gemini API | — |
| `GEMINI_EMBEDDING_MODEL` | модель эмбеддингов. После смены базу нужно загрузить заново | — |

| `GEMINI_LIGHT_MODEL` | модель для переписывания вопроса. Пусто: та же, что для ответов | `gemini-3.5-flash-lite` |
| `LLM_TIMEOUT_MS` | сколько ждать модель, потом «не получилось, попробуй позже» | 30000 |
| `LLM_RETRY_WAIT_MS` | пауза перед повтором при перегрузке Google (429, 503) | 4000 |
| `QDRANT_URL` | адрес Qdrant внутри docker compose | `http://qdrant:6333` |
| `KNOWLEDGE_DB_COLLECTION_NAME` | коллекция в Qdrant | `laws` |
| `TOP_K_VALUE` | сколько кусков закона поиск отдаёт модели | 8 |

Файл `.env` в репозиторий не попадает.

остаётся в базе с пометкой `active: false`, поиск её не видит.

## Проверка качества

Контрольный набор в `data/evaluation.csv`: 10 вопросов «как спросил бы
знакомый» и заранее записанное ожидание для каждого.

| Ожидание | Что должен сделать бот |
| --- | --- |
| `answer` | ответить и сослаться на нужные параграфы |
| `refuse` | честно отказать: вопрос по теме, но ответа в законе нет |
| `partial` | ответ возможен лишь частично, оценивает человек |
| `out_of_scope` | отсеять сразу, на шаге переписывания |

| Замер | Совпало | Проверить | Не совпало | Отчёт |
| --- | --- | --- | --- | --- |
| 47 кусков закона, 3.6 Flash | 7 | 2 | 1 (лимит Google) | `reports/evaluation-before.md` |
| Весь SGB III, 3.6 Flash | 8 | 2 | 0 | `reports/evaluation-after.md` |
| Весь SGB III, правки ответов, 3.5 Flash Lite | 8 | 2 | 0 | `reports/evaluation-lite.md` |

Что нашла ручная проверка и что с этим сделано, в
[docs/project.md](docs/project.md#6-проверка-качества). Флаг `-T` в команде
нужен, чтобы в файл попал только отчёт, а ход проверки остался на экране.

## Как бот отвечает на вопрос

1. Лёгкая модель переписывает вопрос немецкими терминами закона: «дадут ли
   денег, если сам ушёл» становится «Sperrzeit Arbeitsaufgabe ...». Вопрос
   не по теме или о трудовом праве сразу получает свой отказ.
2. Qdrant возвращает 8 ближайших кусков закона, только актуальной версии.
3. Куски ниже порога сходства отбрасываются. Не осталось ни одного: бот
   отвечает «этого я пока не умею», модель не вызывается.
4. Модель отвечает только по этим кускам, по-русски и на «ты», и возвращает
   JSON: текст, номера кусков, вопросы «ещё спрашивают».
5. Источники проверяет код: показываются только куски, которые были в
   контексте.

Для пунктов каталога и кнопок «ещё спрашивают» параграфы известны заранее,
поиск по смыслу там не нужен.

## Как добавить вопрос или подсказку

Правится только `data/questionnaire.json`, код не нужен.

| Тип узла | Что делает |
| --- | --- |
| `choice` | вопрос с кнопками |
| `date` | ответ: дата |
| `periods` | ответ: список мест работы |
| `finding` | бот применяет правило и сообщает результат |
| `message` | сообщение без вопроса |
| `ask` | список подсказок и свободные вопросы |
| `end` | конец разговора |

Подсказка каталога — это запись в `topics` узла `more`: подпись кнопки,
строка описания, вопрос для базы знаний, параграфы (`chunks`) и условие
`showIf` (положение человека, право на пособие). При запуске дерево
проверяется: ссылка на несуществующий узел останавливает программу с
понятной ошибкой.

## Приватность

- Ответы живут только в памяти программы, час. Текст сообщений не пишется ни
  в консоль, ни в файлы.
- Ответы анкеты считает код на месте. В Gemini уходят только свободные
  вопросы и найденные куски закона, об этом сказано в приветствии.
- У программы нет HTTP-сервера, порт Qdrant наружу не открыт. Базу знаний
  пополняет только владелец локальной командой.
- Бот работает только в личных чатах. Фото, файлы и голосовые не открывает.
- «Забудь всё» удаляет переписку из чата. Telegram позволяет удалять только
  сообщения не старше 48 часов.

## Ограничения

- Только SGB III. Jobcenter (SGB II) и трудовое право в базу не входят.
- Правило стажа не учитывает короткие срочные контракты (§ 142 Abs. 2),
  пересечение с прежней Rahmenfrist и периоды без взносов. Срок пособия не
  учитывает прежнее пособие (бот спрашивает и тогда не считает) и сокращение
  из-за Sperrzeit (бот предупреждает словами). Полный список в
  `data/rules.json`, поле `notCoveredYet`.
- В общем ответе про срок пособия модель может написать «за последние
  30 месяцев», хотя § 147 считает работу за 5 лет. Точный срок человеку
  считает код в анкете.
- Бесплатный лимит Gemini: 500 запросов в день у Flash Lite, на вопрос уходит
  два.
